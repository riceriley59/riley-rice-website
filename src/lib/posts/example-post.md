# Welcome to My Blog

This is my first blog post built with **SvelteKit** and **Bun**!

## Why SvelteKit?

SvelteKit is amazing because:

- It's fast and lightweight
- File-based routing makes it easy to organize
- Great developer experience
- Built-in support for markdown
